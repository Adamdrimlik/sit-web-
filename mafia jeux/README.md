# Mafia Online - لعبة المافيا الإلكترونية

نسخة احترافية كاملة من لعبة المافيا المعروفة، مطورة باستخدام Python + Flask + HTML/CSS/JavaScript + SQLite مع إمكانية التطوير لـ PostgreSQL و Socket.IO.

## 🎯 المميزات

### المرحلة الأولى (مكتملة ✅)
- ✅ إنشاء غرفة لعب جديدة
- ✅ الانضمام إلى غرفة موجودة
- ✅ غرفة الانتظار الاحترافية
- ✅ تصميم Dark Theme احترافي
- ✅ واجهة مستخدم متجاوبة
- ✅ إدارة اللاعبين في الوقت الفعلي
- ✅ إعدادات الغرفة (وقت الليل/النهار، الصوت، غرفة الأموات)

### المراحل القادمة
- 🔄 توزيع الأدوار تلقائياً
- 🔄 مراحل اللعب (ليل/نهار)
- 🔄 نظام التصويت
- 🔄 ميزة Voice Chat
- 🔄 غرفة الأموات
- 🔄 إحصائيات اللعبة

## 🛠️ التقنيات المستخدمة

- **Backend**: Python 3.14, Flask 3.0.0
- **Database**: SQLite (قابل للترقية إلى PostgreSQL)
- **Real-time**: Flask-SocketIO, Socket.IO
- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Styling**: CSS Variables, Flexbox, Grid, Responsive Design
- **Architecture**: Flask Blueprints, Application Factory Pattern

## 🚀 التثبيت والتشغيل

### المتطلبات
- Python 3.8 أو أحدث
- pip (مدير الحزم)

### خطوات التثبيت

1. **استنساخ المشروع**
   ```bash
   git clone <repository-url>
   cd mafia-jeux
   ```

2. **تثبيت المكتبات المطلوبة**
   ```bash
   pip install -r requirements.txt
   ```

3. **تشغيل التطبيق**
   ```bash
   # في وضع التطوير
   python -m flask run --host=0.0.0.0 --port=5000

   # أو باستخدام run.py
   python run.py
   ```

4. **فتح المتصفح**
   ```
   http://localhost:5000
   ```

## 🎮 كيفية اللعب

1. **إنشاء غرفة**: اضغط على "إنشاء غرفة جديدة" وأدخل اسمك
2. **مشاركة الرمز**: انسخ رمز الغرفة وشاركه مع أصدقائك
3. **الانضمام**: في جهاز آخر، اضغط على "الانضمام إلى غرفة" وأدخل الرمز
4. **الانتظار**: انتظر حتى ينضم جميع اللاعبين (6-15 لاعب)
5. **بدء اللعبة**: المضيف يمكنه تعديل الإعدادات وبدء اللعبة

## ⚙️ الإعدادات

### إعدادات الغرفة
- **وقت الليل**: الوقت المخصص للعب المافيا (60-120 ثانية)
- **وقت النهار**: الوقت المخصص للتصويت والمناقشة (180-300 ثانية)
- **الصوت**: تفعيل/تعطيل ميزة Voice Chat
- **غرفة الأموات**: السماح للاعبين الخارجين بالتواصل

### إعدادات التطبيق
- **قاعدة البيانات**: SQLite للتطوير، PostgreSQL للإنتاج
- **المنفذ**: 5000 للتطوير، 80/443 للإنتاج
- **الأمان**: HTTPS مطلوب في الإنتاج

## 🗄️ قاعدة البيانات

### جداول البيانات:

#### جدول `rooms` (الغرف)
```
id           : معرف الغرفة
code         : رمز الغرفة (فريد)
host_id      : معرف المضيف
status       : حالة الغرفة (waiting, playing, finished)
created_at   : وقت الإنشاء
started_at   : وقت بدء اللعبة
```

#### جدول `players` (اللاعبون)
```
id           : معرف اللاعب
username     : اسم اللاعب
room_id      : معرف الغرفة المنضم إليها
session_id   : معرف الجلسة
is_host      : هل هو المضيف
role         : دور اللاعب
is_alive     : هل اللاعب حي
joined_at    : وقت الانضمام
```

## 🔌 Socket.IO Events

### Events المُرسلة من Client إلى Server:
- `join_waiting_room` - الانضمام إلى غرفة الانتظار
- `player_joined` - إخطار بانضمام لاعب
- `start_game` - طلب بدء اللعبة

### Events المُرسلة من Server إلى Client:
- `players_updated` - تحديث قائمة اللاعبين
- `game_started` - إخطار ببدء اللعبة
- `error` - رسالة خطأ
